Artbox is now Lumi-o

The project that started as Artbox has been renamed to Lumi-o. It is the same project, with the same maintainer and the same codebase, but heavily reworked since the early Artbox builds. The new name better reflects what the software has become.

Lumi-o is a free, open-source painting and illustration application for Linux, built on the GIMP architecture.
